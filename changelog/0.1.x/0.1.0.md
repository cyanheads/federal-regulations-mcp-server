# 0.1.0 — 2026-06-13

Initial release. A multi-source workflow server over three official US federal regulatory sources: the **Federal Register** (proposed/final rules and notices, keyless), the **eCFR** (codified, point-in-time CFR full text, mirrored locally), and **Regulations.gov** v4 (rulemaking dockets and public comments, key-gated). Every Federal Register document carries the docket ID and CFR-part handles that chain across sources, so a rule can be traced proposal → comments → final → codified text.

## Added

- **`regulations_search_rules`** — search the Federal Register by query, type, agency, date window, and open-for-comment status. Keyless.
- **`regulations_get_document`** — fetch one FR document with the cross-source handles (docket ID, CFR parts, Regulations.gov document ID, comment count) that chain into the comment and codified-text tools. Keyless.
- **`regulations_browse_cfr`** — navigate the CFR hierarchy (structure mode) or full-text-search the codified CFR (search mode, mirror-backed with a live eCFR fallback). Keyless.
- **`regulations_get_cfr_section`** — read the codified text of a CFR section or part, current or point-in-time, served from the local mirror when ready with a live versioner fallback. Keyless.
- **`regulations_get_docket`** — pull a Regulations.gov rulemaking docket and its filed documents. Requires `REGULATIONS_GOV_API_KEY`.
- **`regulations_find_comments`** — fetch public comments on a document or docket (list mode) or one comment's full body and attachments (detail mode), flagging attachment-primary submissions. Requires `REGULATIONS_GOV_API_KEY`.
- **`regulations_list_open_comments`** — rules currently open for comment, closing soonest first. Keyless; enriches comment counts when `REGULATIONS_GOV_API_KEY` is present.
- Resources **`regulations://document/{documentNumber}`** and **`regulations://cfr/{title}/{part}/{section}`** mirroring the document and CFR-section tool outputs for injectable-context clients.
- **eCFR mirror** (MirrorService — embedded SQLite + FTS5) with `mirror:init`, `mirror:refresh`, and `mirror:verify` lifecycle scripts and a weekly refresh cron (HTTP transport). The codified CFR is mirrored once and queried locally for section lookup and full-text search; tools fall back to the live eCFR API before the mirror has completed an init.
- Config: `REGULATIONS_GOV_API_KEY` (optional — the Federal Register and eCFR tools are a complete keyless deployment without it), plus `FEDERAL_REGISTER_BASE_URL`, `ECFR_BASE_URL`, `REGULATIONS_GOV_BASE_URL`, `ECFR_MIRROR_PATH`, `ECFR_MIRROR_REFRESH_CRON`, and `ECFR_MIRROR_TITLES` (scope the mirror to specific CFR titles) overrides.

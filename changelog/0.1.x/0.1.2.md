# 0.1.2 — 2026-06-20

Framework maintenance. Adopts `@cyanheads/mcp-ts-core` `^0.10.6` → `^0.10.9` and re-syncs the bundled skills and devcheck scripts.

## Added

- **`ctx.content` collector** (framework) — handlers and services can now emit image/audio blocks via `ctx.content.image(data, mimeType)` / `.audio(...)`; collected bytes are prepended to `content[]` and never enter `structuredContent`, so media doesn't duplicate into the typed output.
- **`check-dependency-specifiers` devcheck step** — new `scripts/check-dependency-specifiers.ts` (flag `--no-dep-specifiers`) hard-fails on floating specifiers (`latest`, `*`, pre-release dist-tags) in `package.json` and `bun.lock`'s `workspaces` map.
- **Plugin marketplace manifest checks** — `lint:packaging` now validates `.claude-plugin` / `.codex-plugin` manifests (non-empty descriptions, unscoped display name, full install arg), gated by the new `devcheck.config.json` `packaging.pluginManifests` flag.

## Changed

- **Canvas SQL gate** (framework) — `SELECT`-shaped statements that fail to prepare for a reason other than a missing table (mistyped column, unknown function) now throw `ValidationError` with `data.reason: 'invalid_sql'` and the DuckDB binder detail, instead of the misleading `non_select_statement`.
- **Fresh-scaffold devcheck guards** (framework) — changelog-sync and the git-dependent checks (TODOs, tracked secrets, framework antipatterns, skill versions) skip cleanly when `.git` is absent rather than failing.
- **Skill re-sync** — 14 bundled `SKILL.md` files refreshed to their upstream `^0.10.9` versions, mirrored into `.claude/skills/` and `.agents/skills/`.

### Dependency bumps

- `@cyanheads/mcp-ts-core` ^0.10.6 → ^0.10.9
- `@types/node` 25.9.3 → 26.0.0
- `better-sqlite3` ^12.0.0 → ^12.11.1

## Fixed

- **`DuckdbProvider.describe({ tableName })`** (framework) — qualified the pushed `WHERE` filters with the table alias, fixing the ambiguous-column binder error on every filtered `describe()`.

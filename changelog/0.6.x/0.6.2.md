# 0.6.2 — 2026-11-13

## Added

- **Agency filters** in `regulations_search_rules` and `regulations_list_open_comments` accept exact Federal Register names and acronyms case-insensitively. Set `REGULATIONS_RESOLVE_AGENCIES=false` to use slugs only. ([#78](https://github.com/cyanheads/federal-regulations-mcp-server/issues/78))
- **Comment detail** includes the nullable Regulations.gov `subtype` and `category` fields. ([#77](https://github.com/cyanheads/federal-regulations-mcp-server/issues/77))

## Fixed

- **Supporting documents** include the upstream total in document tool and resource results. The tool flags partial lists and directs callers to the docket when a docket ID is available. ([#75](https://github.com/cyanheads/federal-regulations-mcp-server/issues/75))
- **Comment detail** identifies recognized cover notes as attachment-only when attachments are present. ([#76](https://github.com/cyanheads/federal-regulations-mcp-server/issues/76))
- **Federal Register text** renders GPO subscripts, superscripts, and bullets in abstracts and full text. Full-text offsets count the rendered text. ([#82](https://github.com/cyanheads/federal-regulations-mcp-server/issues/82))
- **Startup configuration** loads `.env` before reading server settings and gives explicit environment variables precedence.
- **Scheduled eCFR mirror refresh** skips a run when another sync holds the mirror lease.

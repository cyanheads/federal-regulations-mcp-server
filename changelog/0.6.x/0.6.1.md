# 0.6.1 — 2026-10-29

## Added

- **`regulations_search_rules` filters** — `executive_order_number`, `presidential_document_type`, `president`, `signed_after`/`signed_before`, `significant`, and `effective_after`/`effective_before`. A combination that cannot match (an executive-order filter with `type: RULE`) answers `type_conflict` before any request (#66).
- **`significant` and `presidential`** — on `regulations_get_document`, search rows, and the `document` resource: `significant` is a boolean or null; `presidential` carries type, number, signing date, and president, and is null for non-presidential documents (#66).
- **`regulations_browse_cfr` `mode: "versions"`** — lists the dates a part's or one section's codified text changed (`section`, `changed_since`); each date reads through `regulations_get_cfr_section`'s `date` (#67).
- **`regulations_get_docket` `search_term`** — relevance-ranked document search within a docket (#68).
- **`regulations_get_docket` `document_id`** — detail mode returning the document's file download links (format, size, page count) and attachments (#68).
- **`REGULATIONS_CLAMP_LIMITS`** — `false` restores strict rejection of an over-ceiling `per_page` or `max_chars` (#70).

## Changed

- **`per_page` and `max_chars` ceilings** — a value above a tool's ceiling is served at the ceiling with a notice naming the requested and applied values, on all seven tools; it was rejected with a validation error (#70).
- **`regulations_search_rules` truncation guidance** — names the new filters.
- **Documentation** — the README, design doc, and published guide skill describe the new surface.

## Fixed

- **`regulations_find_comments` unknown docket** — a docket Regulations.gov does not hold answers `not_found`; it returned an empty success (#69).
- **Lowercase Regulations.gov IDs** — docket, document, and comment IDs resolve on `regulations_get_docket` and `regulations_find_comments`' `comment_id` and `document_object_id`; they answered `not_found` (#69).
- **`regulations_get_cfr_section` hierarchy failure** — when eCFR's hierarchy lookup fails, the tool and the `cfr-section` resource return the text with a path built from the cited levels (`Title 40 › Part 141 › § 141.61`) and a notice; the lookup gets one attempt of at most 8 seconds (#71).
- **`regulations_find_comments` attachments** — every attachment is listed in upload order, including ones withheld as copyrighted (`formats: []` plus `restrictReasonType`); they were dropped (#73).

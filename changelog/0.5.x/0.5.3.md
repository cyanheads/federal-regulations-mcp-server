# 0.5.3 — 2026-10-08

## Changed

- **Tool error results carry their request ID**: `content[]` ends `(reason <r> · request <id>)` and the error envelope has `data.requestId`, the id the server's log records for that call carry (mcp-ts-core 0.13.10).
- **Upstream failure messages name the API by origin only**: `Network error during fetch GET https://www.federalregister.gov/…?…` replaces the full request URL, path and query included (mcp-ts-core 0.13.12).
- **Tool arguments are repaired before validation**: a numeric string for a number field (`per_page: "5"`, `title: "40"`) and `null` for an optional field (treated as absent, so defaults apply) are accepted; both were rejected with `-32602` (mcp-ts-core 0.13.14).
- **Recovery hints**: the framework fills each declared hint itself (mcp-ts-core 0.13.10), so the per-throw `ctx.recoveryFor(...)` forwards in services, tools, and the CFR section resource are gone. Callers see the same hints as before.
- **`server.json`**: both npm entries drop the `run start:stdio` / `run start:http` arguments and set `runtimeHint` to `"npx"`; the `streamable-http` entry sets `MCP_TRANSPORT_TYPE` to `http`, so a registry client launching it starts the HTTP transport.
- **Docker image**: production dependencies install in a `deps` stage pinned to `$BUILDPLATFORM` (cross-install with `--os`/`--cpu`, so Bun never runs under QEMU) and musl-only packages are pruned (mcp-ts-core 0.13.10, 0.13.11); base image Bun 1.4.0 → 1.4.2 (0.13.7); `ENV MCP_FORCE_CONSOLE_LOGGING` is removed because nothing read it (0.13.8).
- **`.env.example`** documents the newer framework variables: `MCP_REQUEST_STATE_KEY`, `MCP_LOG_RATE_LIMIT_THRESHOLD` / `MCP_LOG_RATE_LIMIT_WINDOW_MS`, `LOG_TOOL_FAILURE_PAYLOADS` / `LOG_TOOL_FAILURE_PAYLOAD_MAX_BYTES`, and the per-signal `OTEL_EXPORTER_OTLP_*_ENDPOINT` overrides; `MCP_HTTP_HOST` shows `127.0.0.1`.
- **Repo**: `.gitignore` and `.dockerignore` ignore every `.env*` (`.gitignore` keeps `.env.example`, `.env.template`, `.env.sample`; `.dockerignore` also ignores the MCP Registry token files); `.mcpbignore` adds `docs/idea.md`, `logs/`, `.cache/`, `coverage/`, and `tests/`; CodeQL runs one job per language; `package.json` `files` excludes `dist/*.mcpb`, adds `audit:fix` and the `stdio` / `streamable-http` keywords, and pins `packageManager` to `bun@1.4.2`; README badges show MCP SDK `^2.2.0` and Bun `v1.4.2`; `CLAUDE.md` / `AGENTS.md`, `framework-skills/`, and `scripts/` follow the framework 0.13.14 templates.

## Fixed

- **Linear-time regression tests** measure main-thread CPU time (`process.threadCpuUsage`) instead of wall-clock time, so a loaded machine no longer fails them; the request-budget cut-off test runs on fake timers.

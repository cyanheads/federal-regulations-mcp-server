# 0.5.4 — 2026-10-25

- **Framework errors and shutdown**: mcp-ts-core 0.13.15 bounds Zod validation details; 0.13.16 escapes error and trailer text, classifies cancelled calls as `RequestCancelled`, validates numeric configuration at startup, and answers HTTP requests with `503` while draining.

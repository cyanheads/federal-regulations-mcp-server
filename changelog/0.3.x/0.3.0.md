# 0.3.0 — 2026-09-22

## Changed

- **`agencies`** output changed from `string[]` to `{ name, slug }[]` on `regulations_search_rules`, `regulations_get_document`, `regulations_list_open_comments`, and the `regulations://document/{documentNumber}` resource — each entry's `slug` is the value the `agencies` filter accepts; null when the Federal Register lists an agency by raw name only (#24).
- **Federal Register `400`s** whose body names a rejected filter now answer `ValidationError` (`-32007`) with reason `invalid_filter`, naming the parameter (`agencies`, `published_after`/`published_before`, `closing_before`) instead of the framework's unlabeled generic `-32602` (#24).
- **`regulations_list_open_comments` defaults** now include `RULE` (direct and interim final rules that request comment) alongside `PRORULE` (#38); `totalCount` is now the size of the locally paged window, not the Federal Register's reported match count (#32).
- **`regulations_get_document`'s `include_full_text`** no longer advertises a `false` default — passing `offset` or `max_chars` implies it; pairing either with an explicit `include_full_text: false` fails as `full_text_disabled` (#28).
- **`content[]` docket IDs** in `regulations_list_open_comments` now join on `; ` instead of `, ` (a docket ID can itself carry a comma) (#36).

## Added

- **`regulations_search_rules` `order`** input (`relevance` | `newest` | `oldest`), defaulting to `relevance` with a `query` and `newest` without one (#37).
- **`regulations_get_document` full-text paging** — `include_full_text` now returns a bounded window (`max_chars`, default 64,000, up to 200,000) starting at `offset`; the output reports `fullTextLength` and, while text remains, `fullTextNextOffset` to resume from (#28).
- **`regulations_list_open_comments` `type`** input (`PRORULE` | `RULE` | `NOTICE`) to choose which document types are included — `NOTICE` adds information-collection and other notices with comment periods (#38). `totalPages` and `nextPage` enrichment fields describe the paged window.

## Fixed

- **`content[]` tables** in `regulations_search_rules` and `regulations_list_open_comments` now render every agency (and, in `list_open_comments`, every docket ID), not just the first — `structuredContent` already carried the full arrays (#36).
- **`regulations_list_open_comments` ordering** — the tool now fetches the whole open-comment window and sorts by closing date, then document number, instead of sorting one newest-published page (#32).
- **Full-text body** (`unwrapRawText`) now decodes Cloudflare-obfuscated email addresses and reduces links to their text instead of leaving raw `<a href>` markup in `fullText`.

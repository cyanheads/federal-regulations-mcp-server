# 0.2.3 — 2026-08-22

## Changed

- **Request budget** — each MCP request now shares a 45-second wall-clock budget across all upstream calls, retries, and backoff, returning actionable `upstream_unavailable` failures before the default 60-second client timeout.
- **MCP protocol and schemas** — adopts `@cyanheads/mcp-ts-core` 0.12.3 and MCP SDK v2 with 2026-07-28 protocol support; unknown top-level tool arguments are now rejected, and advertised error envelopes use the current JSON Schema form.
- **Domain validation** — semantic service validation now returns `ValidationError` rather than JSON-RPC `InvalidParams`.
- **Federal Register pagination** — `regulations_search_rules` and `regulations_list_open_comments` now require `per_page` 2–100 because an upstream value of 1 silently returns its default page size of 20.
- **Runtime and project maintenance** — refreshes Bun Docker images and production install behavior, TypeScript configuration, maintained project skills, and contributor/community metadata.

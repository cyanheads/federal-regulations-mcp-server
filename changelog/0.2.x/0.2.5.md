# 0.2.5 — 2026-09-20

## Changed

- **Skill tree** moved `skills/` → `framework-skills/`, so a plugin host no longer auto-loads these development skills into every installing agent.
- A handler that unwinds after its request's abort signal fired now classifies `RequestCancelled` (`-32011`) instead of `InternalError` (`-32603`), picked up from the framework bump below.

## Fixed

- **Session mode** — the server now declares `sessionMode: 'stateless'` explicitly instead of relying on the schema default (`auto`, which resolves to `stateful`). An HTTP deployment with no `MCP_SESSION_MODE` set previously resolved `stateful` and issued an `Mcp-Session-Id` header; it now resolves `stateless` and does not. `teardown()` also drains an in-flight mirror refresh before closing the store.
- **Markdown table cells** — `escapePipes` now escapes backslashes before pipes, so a value carrying its own backslash (e.g. `x\|y`) no longer produces a malformed row or an eaten character. Also resolves the open CodeQL alert `js/incomplete-sanitization`.

## Dependencies

- `@cyanheads/mcp-ts-core` ^0.12.3 → ^0.13.6 (error-contract `severity`/`thrownBy` fields, plugin-manifest `userConfig` wiring checks, README version-badge parity check)
- `zod` ^4.4.3 → ^4.6.5, `vitest` ^4.1.11 → ^5.0.1
- dev: `@biomejs/biome`, `@types/node`, `ignore`, `tsc-alias` refreshed; bun engine floor raised to `>=1.4.0`
